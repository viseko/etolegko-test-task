# Internet Speed Checker

Консольный скрипт на Node.js + TypeScript. Делает 10 последовательных запросов к указанному адресу, дожидается полного ответа на каждый и выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

- Node.js 18+ (нужен встроенный `fetch`)

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev -- <url>
```

Или через сборку:

```bash
npm run build
npm start -- <url>
```

Пример:

```bash
npm run dev -- https://i.pinimg.com/originals/f8/bf/57/f8bf5745f38068ce94058544c8aee189.jpg
```

## Единицы измерения

| Величина | Единица | Как считается |
|---|---|---|
| Время запроса | мс | от отправки запроса до получения последнего байта ответа |
| Среднее время | мс | сумма времени всех запросов / 10 |
| Объём данных | МБ (1 МБ = 10⁶ байт) | сумма размеров всех ответов |
| Скорость | Мбит/с (1 Мбит = 10⁶ бит) | общий объём × 8 / общее время |

Используются десятичные единицы (СИ): в них скорость интернета указывают провайдеры и сервисы вроде Speedtest.

## Особенности

- Первые запросы обычно медленнее: DNS-запрос, TCP/TLS-рукопожатие, прогрев соединения.
- Тело ответа читается потоком, поэтому большие файлы не держатся в памяти целиком.
- Запросы отправляются с заголовком `Cache-Control: no-cache`, чтобы промежуточный кэш не завышал результат.
- Ответ с HTTP-ошибкой (4xx/5xx) или некорректный URL завершают скрипт с кодом 1.
